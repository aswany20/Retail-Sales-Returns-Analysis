# Retail Sales & Returns Analysis | Power BI

## 1. Project Overview

This project analyzes six months of sales and returns data from a furniture showroom branch using Power BI.

The main objective is to evaluate overall business performance, identify sales and return patterns, uncover unusual customer behavior, and provide actionable business recommendations.

## 2. Tools & Technologies

- **Power BI:** Data visualization, dashboard development, and business analysis.
- **Power Query:** Data cleaning and transformation.

## 3. Dashboards & Reports

The project consists of three main deliverables:

1. **Overall KPI Dashboard:** Provides an overview of key business performance indicators.
2. **Sales & Returns Dashboard:** Analyzes sales and return trends across different dimensions.
3. **Business Insights Report:** Highlights key findings and actionable recommendations.

## 4. Key Performance Indicators (KPIs)

The analysis focuses on the following metrics:

- Total Orders
- Total Sales
- Quantity Sold
- Return Rate
- Gross Profit

## 5. Key Business Insights

The analysis revealed several important findings:

### Product Performance
- The best-selling products are not necessarily the ones generating the highest Gross Profit.
- Products with more than 50 units sold and zero returns were identified as potential candidates for promotion.
- Several products recorded return rates significantly higher than the branch average.

### Sales & Returns Trends
- Friday recorded the highest sales.
- Sunday had the lowest number of orders but the highest number of returns.
- Sales peaked between 9 PM and 11 PM, while 10 PM recorded the highest number of returns.
- March recorded the highest monthly return rate at 12.9%.

### Customer Analysis
- Two customers showed unusual return patterns, which were flagged for management review.

## 6. Data Limitations

One of the main challenges was the absence of a **Return Reason** column in the dataset.

Although the analysis identified products and patterns associated with higher return rates, it was not possible to determine the actual reasons behind the returns.

For example, returns could be caused by:
- Product defects.
- Products not matching their advertised specifications.
- Other customer-related or operational reasons.

The available data was insufficient to distinguish between these causes.

## 7. Business Recommendations

Based on the findings and identified data limitations, the following recommendations were proposed:

1. **Add a Return Reason Column:** Record the reason for each return, such as product defects, specification or advertisement mismatches, and other reasons.
2. **Track Order Sources:** Record where each order originated, including the showroom, Facebook, Instagram, and WhatsApp.
3. **Record Sales Representatives:** Assign a sales representative to each order to enable more detailed performance analysis.

## 8. Project Conclusion

This project demonstrates how data analysis can go beyond reporting basic sales figures to uncover business patterns, identify potential issues, and support better decision-making.

It also highlights the importance of data completeness in identifying the root causes of business problems and developing more effective solutions.
